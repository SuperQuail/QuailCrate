# 鹌鹑工具箱项目策划

版本 0.1 · 需求草案

鹌鹑工具箱是一套可按需扩展的 Windows 桌面工具箱。用户可以用快捷键打开程序，在桌面分组整理常用项、查看日历和设置壁纸。快速启动、桌面分组、日历和壁纸都通过插件接入宿主。[技术架构](architecture.md) · [首版 UI 设计与参考图](ui-design.md)

## 使用场景

| 场景 | 用户操作和结果 |
| --- | --- |
| 工作中打开应用 | 按 `Alt+Space`，输入应用名，通过方向键选中结果，按回车启动。 |
| 整理桌面常用项 | 创建「工作」「个人」等分组，把现有快捷方式、文件和文件夹拖进分组。重新登录并启动应用后，可以继续使用原来的布局。 |
| 查看日期 | 回到桌面查看当月日历和今天的日期，需要时向前或向后翻月。 |
| 使用壁纸 | 从本地选图设置 Windows 壁纸，或继续使用 Wallpaper Engine 的壁纸，同时使用鹌鹑工具箱的分组和日历。 |
| 按需启用工具 | 在设置里查看插件状态并启停功能。开发者可以通过 Lua 或原生 DLL 实现插件，在同一个工具箱中使用。 |

## 首版功能

### 快速启动

- 默认热键为 `Alt+Space`。唤起面板后输入框获得焦点，输入时刷新结果，方向键选择，回车执行，Esc 关闭。中文输入法组字期间由输入法处理确认键。
- 按已安装应用的显示名匹配。索引覆盖开始菜单的桌面程序和可枚举的打包应用。同名结果显示来源，便于区分。索引在后台建立及刷新。
- 允许修改热键。注册失败时显示占用或失败状态，并让用户重新选键。Windows 窗口菜单和 PowerToys Run 均使用这组按键，实际注册行为纳入原型验证。[Windows 快捷键](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec) · [PowerToys Run](https://learn.microsoft.com/zh-cn/windows/powertoys/run)

### 桌面分组

- 草案采用鹌鹑工具箱管理的分组面板。用户可以创建、命名、移动和删除分组，并在组内拖拽排序。
- 支持拖入桌面或资源管理器里的应用快捷方式、文件和文件夹。拖入和移出操作管理分组中的引用。点击条目时用 Windows 打开对应目标，目标失效时提示用户。
- 保存分组内容和位置。返回桌面时可以操作面板，显示器配置变化后面板仍可找回。把现有 Windows 桌面图标直接纳入分组管理的交互待确认。

### 桌面日历

- 展示本地日期的月历，高亮今天，支持切换月份和返回本月。跨午夜、系统时间变更或休眠恢复后，更新日期显示。
- 保存面板位置。日程录入、提醒和外部日历同步的需求待确认。

### 壁纸与 Wallpaper Engine

- 壁纸插件支持选择本地 JPG 或 PNG，交给 Windows 设为桌面壁纸。
- 草案将「Wallpaper」理解为 Steam 上的 Wallpaper Engine。首版兼容范围按共存估算。用户可以继续在 Wallpaper Engine 中切换动态壁纸，鹌鹑工具箱的分组和日历保持可见、可交互。
- 如果希望在鹌鹑工具箱内控制 Wallpaper Engine，可通过其官方命令行接入切换、暂停等能力。是否在首版加入这项联动待确认。[Wallpaper Engine 命令行文档](https://help.wallpaperengine.io/zh/functionality/cli.html)

### 插件和设置

- 快速启动、桌面分组、桌面日历和系统壁纸均作为随应用交付的功能插件。公共唤起面板、桌面挂载能力与托盘设置入口由宿主提供。
- 插件列表显示名称、Lua 或 DLL 运行时、启用状态和加载失败原因。启停后根据插件状态添加或撤下搜索结果、命令和桌面组件。
- 首版交付同时验证两种运行时。Lua 承载上述内置功能，随发布包提供一个原生 DLL 插件用来验证加载、调用和停用流程。首版估算按项目方维护的 DLL 随应用发布，第三方自助安装方式待确认。

## 第三方插件方向

插件作者可以组合使用搜索、命令和桌面组件。例如，待办插件可以在桌面显示清单，也可以在唤起面板里搜索事项并标记完成。

| 方向 | 插件示例 | 使用方式 |
| --- | --- | --- |
| **扩展搜索** | Everything 文件搜索、浏览器书签、最近项目 | 按 `Alt+Space` 搜文件名、书签或项目，回车打开。 |
| **即时工具** | 计算器、单位换算、时间戳转换、常用文本片段 | 在唤起面板输入 `15 * 24` 查看结果，或选中文本片段后复制。 |
| **桌面组件** | 待办清单、番茄钟、天气、CPU 和内存状态 | 把组件放到桌面，点击完成待办、开始计时或查看状态。 |
| **快捷工作流** | 项目启动、会议准备、常用文件批量打开 | 执行一条命令，打开项目所需的 IDE、目录和文档。 |
| **桌面个性化** | 工作与游戏布局、定时换壁纸、Wallpaper Engine 控制 | 选用「工作」布局时，显示工作分组和日历并应用相应壁纸。 |
| **服务集成** | GitHub 工单、日历订阅、团队待办 | 在桌面查看近期事项，在唤起面板按标题查找并打开原页面。 |

Lua 适合换算、组件逻辑和工作流编排。DLL 可承担大规模本地索引、截图 OCR 和图像处理，再把结果交给同一套搜索、命令或组件接口。需要联网、读取目录、定时触发或跨插件切换布局的例子依赖对应的宿主能力。[第三方插件所需的宿主能力](architecture.md#第三方插件所需的宿主能力)

这些方向用于规划插件生态，首版交付以以下验收条件为准。

## 验收条件

草案以 Windows 11 x64 作为首轮验收环境。兼容范围和性能基线在原型验证后定稿。

| 编号 | 验收场景 | 通过条件 |
| --- | --- | --- |
| A01 | 热键唤起与冲突 | `Alt+Space` 可注册时能唤起面板并立即输入。已被其他应用占用时有提示，设置可用组合键后能正常唤起。 |
| A02 | 搜索并打开应用 | 用中文、英文名称查询，选中后能启动测试机上的桌面应用和打包应用。无结果时有反馈。按 Esc 关闭面板。 |
| A03 | 分组编辑和恢复 | 建组、拖入三类条目、排序、移动面板后重启应用，组名、顺序和位置恢复。移动或移除引用后，能从原位置打开源文件。 |
| A04 | 日历翻月 | 当前日期高亮正确，包括跨月、跨年与闰日。恢复休眠后能显示当天日期。 |
| A05 | 系统壁纸 | 在使用系统背景的测试桌面上，选取有效本地图片后能看到更新。路径失效时提示失败。 |
| A06 | 桌面层与壁纸共存 | 在 Wallpaper Engine 运行时切换动态壁纸，使用 `Win+D` 返回桌面后分组与日历仍可点击。覆盖单屏、双屏及不同缩放比例的代表性配置。 |
| A07 | 两种插件运行时 | Lua 和 DLL 插件都能被发现、启用和调用。停用后撤下贡献项，恢复启用后可再次使用。版本不匹配时显示原因，其他已启用插件继续运行。 |
| A08 | 设置持久化 | 重新登录并启动宿主后恢复热键设置、分组和组件位置、插件启用状态。应用索引完成后可以再次搜索已安装应用。 |

### 性能与诊断

- 原型测量热键到输入框可用、输入到首批结果两段耗时。建议在宿主已常驻、约 1,000 个应用索引项的测试配置下，以 P95 分别不超过 150 ms 和 200 ms 作为初始参考。记录机器配置和实际样本数据，再定发布目标。
- 搜索和索引更新由后台处理，输入、拖拽与关闭面板保持响应。快速连续输入时，面板显示当前查询的结果。
- 插件或系统接口出错时，在对应操作或设置页提供可理解的状态。插件 ID、错误码和耗时写入本机运行日志。

## 实施里程碑

| 里程碑 | 完成条件 |
| --- | --- |
| M0 平台原型 | 跑通全局热键、焦点与冲突处理，验证桌面组件的层级、`Win+D`、Wallpaper Engine 切换和 Explorer 重启。分别调用一个 Lua 和一个 DLL 插件，确认宿主接口能覆盖两种运行时。 |
| M1 启动与插件管理 | 做通应用索引、搜索、执行及插件启停。完成错误状态和设置持久化，覆盖 A01、A02 和 A07 的主流程。 |
| M2 桌面功能 | 交付可用的分组、月历和本地壁纸插件，并完成双屏、DPI 和壁纸共存验收。 |
| M3 首版候选 | 完整执行 A01–A08、复测性能并记录适用环境。验证发布包可在干净的 Windows 测试环境安装、启动和恢复配置。 |
