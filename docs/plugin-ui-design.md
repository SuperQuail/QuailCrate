# 插件 UI 与通用控件库设计

月历、分组与快速启动已使用 v2 视图协议。工作台插件声明设置分区、卡片和托盘入口，宿主保留插件管理恢复入口。第三方作者可查阅[已实现的 UI API](../pluginapi/v2/UI.CN.md)。下文也记录了输入、无障碍和性能验收的设计目标。服务与授权见[插件平台架构](plugin-platform-architecture.md)，原有包可继续使用[公共插件 API v1](../pluginapi/v1/README.CN.md)。

## 从现有界面迁移什么

| 界面 | 已实现的 v1 | v2 的交付边界 |
| --- | --- | --- |
| 快速启动 | 插件提供搜索结果和打开命令。宿主拼装输入框、结果行和页脚 | 启动器插件声明浮层、结果模板、菜单扩展点和按键操作。宿主处理快捷键、IME、弹窗位置及列表绘制。[快速启动渲染](../internal/winui/launcher_windows.go) |
| 月历 | Lua 计算星期标题和 42 个日期格，处理翻月、选日及跨日刷新。渲染器还按 `telemetry` 等控件 ID 决定外观 | 月历插件组合工具栏、七列网格、摘要与进度条。按钮强调色、表头角色和进度值由视图显式给出。[月历插件](../plugins/calendar/plugin.lua) · [桌面控件渲染](../internal/gioui/widget.go) |
| 桌面分组 | Lua 声明列表、标签页和菜单。窗口宿主识别部分按钮 ID，处理添加菜单和拖放 | 分组插件声明菜单打开方式、作用对象和操作。宿主负责菜单定位、拖动反馈、插入位置与鼠标捕获。插件确认重排并保存条目。[分组插件](../plugins/desktop-groups/plugin.lua) · [桌面窗口](../internal/winui/desktop_windows.go) |

## 控件库如何交付

| 交付物 | 首批内容 | 使用方式 |
| --- | --- | --- |
| **公共 UI 协议** | 行、列、网格、文字、图标、按钮、输入框、虚拟列表和进度条。菜单、标签页和选择器使用共同的项与事件约定 | Lua 与 DLL 提交相同的 JSON 控件树。协议规定布局、交互、样式和可访问性语义 |
| **宿主渲染器** | 布局、命中测试、本地滚动与选择、键盘焦点、原生文本输入、图标缓存和主题 | 桌面窗口、应用窗口和浮层适配同一套控件语义。Windows 的窗口层级、焦点恢复、DPI 与文件拖放由各窗口适配层处理 |
| **组合组件 SDK** | 工具栏、搜索结果行、空状态，以及多个插件确实需要的日期选择器 | Lua 辅助函数或 C/C++ 构造函数生成基础节点。第三方可将指定版本的组合组件随自己的插件打包。复用日期选择器只需组件代码。读取另一个日历插件的日程才需要服务调用 |

页面所属插件决定内容与操作。快速启动浮层、桌面组件、独立应用或标签页都能承载插件视图。设置页和托盘菜单也由相应插件声明分区、入口、文案和排序。宿主管理窗口生命周期、热键冲突、托盘图标及菜单可表达的项目类型，保留可恢复插件管理的系统入口。权限决定由宿主核验，授权界面的调用来源和实际授权范围取自宿主记录。

## 控件树与事件

用户可以安装多个声明快速启动浮层的界面插件。核心把全局唤起热键交给用户选定的一个界面实现，搜索提供者仍可同时启用。停用当前界面时，恢复随包默认实现或从管理入口选择其他实现。桌面组件按插件 ID 和组件实例 ID 分配窗口，两个插件都叫“日历”也能各自保存布局。

v2 清单通过 `schemaVersion: 2`、`hostApiVersion: 2` 和 `uiVersion: 2` 声明所需协议。一个视图包含一个 `root`。节点的 `type` 决定控件行为，`id` 在当前视图实例内唯一，`props` 保存声明值，`children` 表示有序子节点，`events` 把控件公开的事件绑定到插件自己的动作。可省略空属性和子节点。宿主在安装视图前检查节点类型、ID、属性类型、事件、树深和节点数量。校验失败时提供节点位置和原因。

下面是月历工具栏的完整视图片段。日期和翻月逻辑归插件，`jump` 的外观来自 `variant`。图标按钮的名称也供读屏使用。

```json
{
  "uiVersion": 2,
  "root": {
    "type": "row",
    "id": "month-navigation",
    "props": { "label": "月份导航" },
    "children": [
      { "type": "text", "id": "caption", "props": { "text": "2026 年 11 月", "grow": 1 } },
      { "type": "button", "id": "back", "props": { "icon": "chevron-left", "label": "上个月" }, "events": { "activate": "calendar.previousMonth" } },
      { "type": "button", "id": "jump", "props": { "text": "今天", "label": "返回本月今天", "variant": "accent" }, "events": { "activate": "calendar.goToToday" } },
      { "type": "button", "id": "forward", "props": { "icon": "chevron-right", "label": "下个月" }, "events": { "activate": "calendar.nextMonth" } }
    ]
  }
}
```

完整月历在纵向容器中依次放入该工具栏、网格、摘要和进度条。插件给七个星期标题标注表头角色。每个日期项的 `key` 使用完整日期，例如 `2026-11-25`。当前日期标记和用户选中状态分别表达，读屏可同时读出日期、是否今天及是否选中。需要农历时，在日期格模板内增添一行文字即可。周末色可由插件声明为主题色并给出系统主题回退。高对比度下仍用文字或标记区分状态。

列表和网格将业务项与项模板分开。每项有稳定的 `key`。模板可将数据字段绑定到文字、图标及徽标等已声明属性。宿主只为可见区及其附近的项执行布局。更新后，同一节点和业务项可复用焦点与滚动位置。项被移除时，将选择移到仍可用的相邻项。插件处理事件时使用动作 ID 和业务项 key，避免用显示文字或行号定位数据。

## 输入、更新与跨插件动作

- **输入与键盘。** 快速启动将初始焦点交给搜索框。组合输入期间的方向键、回车和 Esc 先由 IME 处理。提交文本后再更新查询。控件在本地处理普通导航键和高精度滚轮，到达边界后跳过无效重绘。网格内用方向键移动焦点，Tab 可离开网格。菜单提供与鼠标等价的键盘操作。分组条目重排同时提供键盘入口。
- **业务状态。** 翻月、选择日期、执行搜索结果和提交重排等动作投递给所属插件。宿主随交互附上插件实例、视图会话与修订号，核对本次视图确实声明了对应节点、项和动作。切换标签页、关闭窗口或重新加载插件后，丢弃旧回执。查询结果按当前查询更新。等待结果时不能激活上一次查询的条目。
- **绘制与响应。** 悬浮、滚动、插入位置提示和拖动窗口直接使用本地布局。焦点或选择变化只更新受影响区域。图标完成加载时按当前可见 key 重绘。后台插件响应可以更新下一帧，UI 线程保持可输入。适配器须在呈现前完成一帧。原生输入框独立管理输入、光标和 IME。
- **搜索结果菜单。** 启动器从 `quailcrate.search.provider` 汇集结果，并在 `quailcrate.result.actions` 接收附加动作。宿主把用户激活的结果路由回原提供者。分组插件可为应用引用贡献“添加到分组”，通过 `quailcrate.groups.items` 的 `add` 方法处理请求、选择目标和保存。分组插件停用后撤下菜单项，搜索及打开应用仍可使用。

## 迁移与验收

1. **保留 v1 行为。** 适配层将平铺的 `View.Controls`、标题按钮、菜单及旧版日历样式翻译为目标节点，并将 v2 控件交互还原为旧插件预期的 `widget.action` 或 `tab.action`。分别运行旧版 Lua 组件与应用标签页。[v1 视图结构](../pluginapi/v1/types.go) · [现有控件校验](../internal/plugins/validate.go)
2. **验收基础控件。** 分别启用 Lua 和 DLL 桌面月历，检查 42 个日期格、翻月、跨日、键盘焦点和不同 DPI。修改工具栏或摘要节点 ID 后，样式和操作仍由属性与绑定决定。在分组中验证列表切换网格、拖入、重排、取消和失效项移除。
3. **在真实快速启动窗口验证交互。** 用 25 条带图标的结果和 5 行可见区，连续用滚轮和方向键往返，记录输入至呈现的中位数和 P95。覆盖半刻度滚轮、列表两端及延迟图标。检查滚动期间没有清屏帧，单个图标到达只更新对应位置。用慢速搜索插件验证快速输入、关闭再打开及迟到结果。
4. **让第三方独立接入。** Lua 和 Windows DLL 分别返回同一份示例控件树，比较按钮行为、无障碍名称与主题效果。一个独立插件仅凭公共 SDK 为分组或搜索提供新动作，停用后该入口随之移除，其余页面继续工作。
